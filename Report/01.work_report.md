# MagicSquare 작업 보고서

## 작업 개요

MagicSquare 프로젝트 기준으로 `.cursorrules`를 작성하고, ECB 패턴의 `entity`
레이어에 `User` 엔티티 클래스와 pytest 테스트 파일을 추가했다.

## 생성 및 수정 파일

- `.cursorrules`
- `entity/__init__.py`
- `entity/user.py`
- `tests/entity/test_user.py`

## .cursorrules 주요 내용

- Python 3.10+ 기준
- PEP8 엄격 준수
- 모든 함수 파라미터와 반환값 타입힌트 필수
- public 메서드 Google 스타일 docstring 필수
- Black 기준 최대 줄 길이 88
- ECB 패턴 적용
  - `boundary`: 외부 입출력 담당
  - `control`: 비즈니스 로직 담당
  - `entity`: 도메인 데이터 및 규칙 담당
- TDD 단계 정의
  - red_phase
  - green_phase
  - refactor_phase
- pytest 기반 테스트 규칙 정의
- 금지 패턴 정의
  - `print()`
  - 하드코딩 상수
  - except 단독 사용
- Cursor AI 행동 규칙 정의

## User 엔티티

파일: `entity/user.py`

`User`는 MagicSquare 도메인의 사용자 정보를 표현하는 entity 클래스다.

주요 특징:

- `dataclass(frozen=True)` 사용
- `user_id: int`
- `username: str`
- `user_id`는 양수만 허용
- `username`은 앞뒤 공백을 제거하고 빈 문자열을 허용하지 않음
- `can_create_magic_square()` 메서드 제공

## 테스트

파일: `tests/entity/test_user.py`

pytest 기반으로 다음 동작을 검증한다.

- username 앞뒤 공백 제거
- 0 이하 `user_id` 거부
- 빈 username 거부
- 유효한 사용자의 마방진 생성 가능 여부 확인

테스트는 AAA(Arrange-Act-Assert) 패턴을 따르도록 작성했다.

## 검증 결과

- `ReadLints`: 오류 없음
- `python -m pytest`: 현재 환경에서 `python` 명령 실행 실패
- `py -m pytest`: 현재 환경에서 `py` 런처를 찾지 못함

## 비고

실행하지 못했다.
